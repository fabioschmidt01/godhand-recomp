# mods

Uma pasta por mod, com os arquivos que substituem os do disco. O app reconhece sozinho (aba **Mods** ou
`recomp.bat mods`). Ainda são só listados: a substituição de arquivos entra numa fase posterior.

Ao ativar, desativar ou reordenar pela interface, o app grava o estado em `mods.toml`.

Mod não é patch: arquivos `.xdelta` e `.pnach` ficam em `../patches/`. Texturas ficam em `../textures/`.

Só este arquivo é versionado.
